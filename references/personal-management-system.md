# 个人管理系统

本文档定义了个人管理系统的**分类、命名、同步、维护**规则。个人所有平台均遵循此文档要求。

---

## 一、设计原则

1. **分类即标签** — 目录名即是分类，一看即知归属
2. **文件名自描述** — 脱离文件夹后只看文件名也能知道它是什么、什么时候的
3. **目录结构即同步策略** — 看一级目录名就知道该不该同步、同步到哪些设备
4. **规则少、可查、不靠记** — 所有规则写在这一份文档里

---

## 二、分类架构

十类按重要程度排列：根基 → 源头 → 主业 → 成长 → 表达 → 工具 → 保障 → 体验 → 扩展。

| 编号   | 分类   | 定位          | 示例内容       |
| ---- | ---- | ----------- | ---------- |
| `00` | 个人档案 | 身份根基        | 证照学历、党籍    |
| `01` | 教育经历 | 学术源头        | XX大学       |
| `02` | 工作经历 | 职业经历        | XX公司       |
| `03` | 笔记空间 | 日常积累        | 读书笔记、日常灵感  |
| `04` | 思考创作 | 思想表达        | 博客、随笔、反思   |
| `05` | 参考资料 | 知识库存        | 书籍、论文、工具手册 |
| `06` | 健康医疗 | 身体底牌        | 体检报告、病历    |
| `07` | 财务管理 | 经济保障        | 投资记录、保单    |
| `08` | 生活记录 | 人生体验        | 照片、旅行      |
| `09` | 个人项目 | 个人扩展        | 个人作品、独立项目  |
| `99` | 大型文件 | *(存储层，排最后)* | 视频、安装包、备份  |

### 关键约定

- **工作按公司分**：`02-工作经历/` 下每家公司一个独立目录，雇佣人事（股权、绩效、报销）跟公司走。换工作时整个公司目录归档。
- **大文件分离**：`99-大型文件/` 为纯存储层，不属于分类体系，不参与同步。50MB 以上的文件放此处，在分类目录中用 `.link.md` 占位索引。

## 三、命名规范

### 3.1 目录命名

| 情况 | 规则 | 示例 |
|------|------|------|
| 有逻辑顺序 | `数字前缀-名称` | `01-方向A/` `02-方向B/` |
| 日期分组 | `YYYY-MM` | `2022-12/` `2023-11/` |
| 独立容器 | 直接用名称 | `项目A/` `工具B/` `参考论文/` |

数字间隔使用 `01, 02, 05...`，方便未来在中间插入新类别。

### 3.2 文件命名

| 类型             | 规则                                         | 示例                        |
| -------------- | ------------------------------------------ | ------------------------- |
| **A. 自己产出的文档** | `YYYYMMDD-描述[-v版本].扩展名`                    | `20230715-项目进度跟踪.xlsx`    |
| **B. 下载的参考资料** | **按资料实际标题命名**（从 PDF 元数据或正文提取，不保留下载时的随机文件名） | `某领域综述2024.pdf`           |
| **C. 官方文件**    | **保留原名**（有法律效力，原名是身份一部分）                   | `张三-2024下半年绩效评价表-签名版.pdf` |
| **D. 代码项目**    | **不改**（遵循项目自身命名规范）                         |                           |

## 四、同步架构

### 4.1 同步链路

```
IMA（云端笔记）
  │  ima-skill 单向拉取
  ▼
个人电脑（本地 PMS）
  │  rsync
  ▼
服务器（备份）
```

公司电脑同理，只同步工作相关内容。

### 4.2 按设备同步策略

| 目录 | 个人电脑 | 公司电脑 | 服务器备份 | 来源 |
|------|:---:|:---:|:---:|------|
| `00-个人档案/` | ✅ | ❌ | ❌ | 本地录入 |
| `01-教育经历/` | ✅ | ✅ | ✅ | 本地录入 |
| `02-工作经历/` | ✅ | ✅ | ✅ | 本地录入 |
| `03-笔记空间/` | ✅ | ✅ | ✅ | IMA 单向同步 |
| `04-思考创作/` | ✅ | ✅ | ✅ | 本地录入 |
| `05-参考资料/` | ✅ | ✅ | ✅ | 下载 |
| `06-健康医疗/` | ✅ | ❌ | ❌ | 本地录入 |
| `07-财务管理/` | ✅ | ❌ | ❌ | 本地录入 |
| `08-生活记录/` | ✅ | ❌ | ❌ | 本地录入 |
| `09-个人项目/` | ✅ | 按需 | 按需 | 本地录入 |
| `99-大型文件/` | ✅ | ❌ | ❌ | 本地录入 |

> **注**：`03-笔记空间/` 的数据源头是 IMA，通过 ima-skill 单向拉取到本地，再同步到公司电脑和服务器。个人电脑为全量，公司电脑和服务器按需排除敏感目录。

### 4.3 IMA → 本地 → 服务器 链路

```
IMA app  ──(ima-skill)──►  个人电脑 PMS  ──(rsync/定时任务)──►  服务器
                              │
                              └──(Syncthing/网盘)──►  公司电脑 PMS
```

1. **IMA → 本地**：手动触发 `/ima-skill` + `/personal-management-system` 同步，笔记原封不动写入 `03-笔记空间/` 同名子目录
2. **本地 → 公司电脑**：通过 Syncthing 或网盘实时同步 `02-工作经历/`、`03-笔记空间/`、`05-参考资料/`
3. **本地 → 服务器**：通过 rsync 定时任务（每日 19:00）全量备份到服务器

### 4.4 公司电脑差异化

公司电脑不同步以下目录：`00-个人档案/`、`06-健康医疗/`、`07-财务管理/`、`08-生活记录/`、`99-大型文件/`。`09-个人项目/` 按需决定。

额外过滤（Syncthing Web UI → 忽略模式，仅公司电脑生效）：

```
*.mp4
*.iso
*.dmg
```

### 4.5 大文件处理

`99-大型文件/` 为纯存储层，不参与同步：

| 文件大小 | 放哪里 | 分类目录留什么 |
|----------|--------|---------------|
| < 50MB | 直接放对应分类目录 | 文件本身 |
| 50MB–500MB | `99-大型文件/` | `.link.md` 占位文件 |
| > 500MB | 移动硬盘 / NAS | `.link.md` 占位文件 |

所有同步工具排除 `99-大型文件/` 目录。

## 五、同步工具速查

| 工具 | 适用场景 | 特点 |
|------|----------|------|
| **Syncthing** | 公司 ↔ 家里 ↔ 服务器 | 点对点、无中心服务器、免费、数据不出机房 |
| **网盘客户端**（OneDrive / iCloud / 百度） | 个人多设备 | 有云端中转、跨平台客户端完善 |
| **Git** | 代码项目 | 版本管理，工作目录下的独立仓 |
| **rsync** | 服务器 ↔ 本地 | 一次性批量同步 |

选择建议：代码用 Git，文档用 Syncthing 或已有网盘，个人档案不同步。

### 5.1 WSL rsync 快速同步

Windows 本地无原生 rsync，通过 WSL 直接调用。

**前提**：SSH 密钥已部署到服务器（免密登录）。

**用法**（分两步，执行前确认目标）：

```powershell
# 1. 先 dry-run 预览
wsl rsync -avzh --dry-run `
  --exclude='00-个人档案/' --exclude='06-健康医疗/' `
  --exclude='07-财务管理/' --exclude='99-大型文件/' `
  --exclude='.git/' `
  /mnt/c/<用户路径>/个人管理系统/ `
  <用户>@<服务器地址>:/<目标路径>/

# 2. 确认目标地址无误后，去掉 --dry-run 执行
wsl rsync -avzh --progress `
  --exclude='00-个人档案/' --exclude='06-健康医疗/' `
  --exclude='07-财务管理/' --exclude='99-大型文件/' `
  --exclude='.git/' `
  /mnt/c/<用户路径>/个人管理系统/ `
  <用户>@<服务器地址>:/<目标路径>/
```

> **注意**：第二步执行前必须确认目标地址正确，避免覆盖错误位置。

## 六、日常操作指南

### 新增内容

1. **定分类** — 属于哪个一级？哪个二级？三级要不要？
2. **命名** — 自己产出的：`YYYYMMDD-描述.扩展名`；下载的/官方的：保留原名
3. **放对位置** — 放入对应分类目录
4. **确认同步** — 检查是否放入了对应同步单元的目录

### 查找内容

- 按目录层级逐级进入，或直接 `find` / Spotlight 搜文件名

### 定期维护

- 每季度清理过期中间文件（如实验截图、临时导出数据）
- 每年归档一次不再活跃的项目（移入年份归档目录）
- 新增分类时更新本文档
- `00-个人档案/` 保持只增不减（身份文件永久保留）
